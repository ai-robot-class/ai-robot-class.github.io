| 14 | 为什么要重温 | 为什么具身智能要重温这些看似老派的数学？因为在传统 SLAM 时代，几何操作藏在优化器内部，工程师不用直接面对旋转空间的结构。但到了深度学习加具身智能时代，几何操作暴露到了网络的前向和反向传播里。这就要求：网络输出的动作必须物理合法，大范围姿态优化必须可微、无奇异，生成的轨迹必须严格可行。绕路走不通了，必须直面旋转的真实结构。 |
| 15 | 核心痛点 | 这里是最核心的痛点：旋转不能直接相加。两个旋转矩阵直接相加，结果一般不再满足 R 转置乘 R 等于单位阵，也就是不再是一个合法旋转，物理仿真会崩溃。正确的做法是：旋转要相乘而不是相加；要做优化、做梯度下降，必须先回到它的切空间——也就是李代数——再说。记住这个比喻：李群是弯曲的球面，李代数是平坦的地图。 |
| 16 | 四种姿态表示 | 这张表对比四种姿态表示。欧拉角三个数，直观可读，但有万向锁、插值不顺滑；旋转矩阵九个数，精确但冗余，还带六个约束；四元数四个数，紧凑、无万向锁、插值顺滑，但要理解双覆盖；轴角三个数，几何意义清晰，等价于李代数 so3 向量。工程结论是：显示用欧拉角，推导用旋转矩阵，存储用四元数，优化用李代数。 |
| 17 | 万向锁本质 | 欧拉角的致命缺陷是万向锁。一个常见误区是以为欧拉角三个轴始终两两正交，其实不是。以 ZYX 顺序为例，先绕 Z 转偏航，新的 Y 轴就变了；再绕新 Y 转俯仰，新的 X 轴又变了。每一步的旋转轴都依赖前一步的姿态。当俯仰角到正负九十度时，偏航轴和滚转轴重合，三个自由度退化成两个，丢掉一个自由度，表现为姿态突变、某些朝向无法到达。 |
| 18 | 万向锁动画 | 动画里三个旋转环，红色是外环绕 Z，绿色是中环，蓝色是内环。当俯仰角转到九十度时，红环和绿环的旋转轴对齐，状态卡变红，自由度从三降到二。这就是万向锁。所以工程上，所有内部计算都用四元数加李代数，欧拉角只留给界面显示和人机交互。 |
| 19 | SO3 定义 | 李群 SO3，是三维空间里所有合法纯旋转的集合。定义是：R 是三乘三矩阵，满足 R 转置乘 R 等于单位阵，并且行列式等于正一。前一个约束保证形状不变，长度和角度都保持；后一个约束保证是右手旋转，排除镜像反射。名字里 Special 对应行列式正一，Orthogonal 对应正交，Group 对应群，每个词都有它的物理含义。 |
| 20 | 约束推导 | 这两个约束怎么来的？正交性：旋转不改变长度，所以 v 撇模长平方等于 v 模长平方，把它展开成 v 转置乘 R 转置乘 R 乘 v，对任意 v 成立，就推出 R 转置乘 R 等于单位阵。行列式：对这个等式两边取行列式，得到行列式 R 的平方等于一，所以等于正负一；负一对应镜像反射，不是真实旋转，于是取正一。 |
| 21 | SO3 群结构 | SO3 之所以叫群，是因为它满足四条性质：封闭性，两次旋转合成还是旋转；结合律，旋转可以分组进行；单位元，不转也是一种旋转；逆元，任何旋转都可逆，而且逆等于转置。最后这条特别有工程价值——在 SLAM 里频繁用到，因为它把昂贵的矩阵求逆，变成了几乎免费的转置。 |
| 22 | SO3 维度 | SO3 有个反直觉的地方：旋转矩阵有九个元素，但只有三个自由度。因为 R 转置乘 R 等于单位阵这个条件，由于结果是对称矩阵，实际提供了六个独立约束，九减六等于三，正好和轴角的三个数一致。所以 SO3 是九维空间里的一个三维光滑流形。流形的意思是：局部看像平面，整体却是弯的，就像地球表面——这就是不能对旋转直接做加法的根本原因。 |
| 23 | SE3 定义 | 李群 SE3，是三维空间里所有刚体运动的集合，也就是旋转加平移。它就是那个四乘四的齐次变换矩阵 T，左上是属于 SO3 的旋转，右上是平移向量。为什么要齐次化？因为 R 乘 p 加 t 不是矩阵乘法，没法连乘；升维之后变成纯矩阵乘法，可以任意连乘，T_AB 乘 T_BC 等于 T_AC。 |
| 24 | SE3 的逆 | SE3 的逆有解析公式，不需要做数值求逆：逆的旋转块是 R 转置，平移块是负的 R 转置乘 t。推导很简单，要求 T 乘 T 逆等于单位阵，分别解出旋转块和平移块即可。维度方面，SE3 是六自由度，三个旋转加三个平移，是十六维空间里的一个六维光滑流形。 |
| 25 | SE3 应用 | SE3 在工程里无处不在：机械臂末端相对基座的位姿、SLAM 里相机相对世界的外参、无人机机体相对地面的状态、位姿图里每个关键帧的节点、抓取时物体相对相机的位姿——全都是一个 SE3 矩阵。可以说，只要涉及到刚体在空间里的位置和朝向，背后都是 SE3。 |
| 26 | so3 球面比喻 | 现在讲李代数。用一个比喻：李群 SO3 和 SE3 像弯曲的球面，你不能把北京的坐标和纽约的坐标直接相加，也不好直接求导。而李代数 so3 和 se3，像把球面局部展开成的平面地图，在地图上可以加减、可以求梯度。它们之间通过指数映射和对数映射来回切换。优化就在地图上做，结果再贴回球面。李代数，就是李群在单位元处的切空间。 |
| 27 | so3 定义 | so3 是所有三乘三反对称矩阵的集合，它和三维向量一一对应。给一个向量 w，它的反对称化叫 hat 算子，把三个分量摆成一个反对称矩阵。最重要的恒等式是：w 的 hat 矩阵乘以 v，等于 w 叉乘 v——也就是说，反对称矩阵就是叉乘的矩阵形式。这个性质后面会反复用到。 |
| 28 | so3 推导 | so3 是怎么从 SO3 切出来的？出发点是旋转随时间变化，R 乘 R 转置始终等于单位阵。两边对时间求导，整理后发现 R 导数乘 R 转置是一个反对称矩阵，于是可以写成 w 的 hat 形式，得到 R 导数等于 w 的 hat 乘 R。物理上，w 就是瞬时角速度。在单位元处，R 导数就等于 w 的 hat。所以 so3 描述的，就是旋转的微小增量、旋转的速度方向。 |
| 29 | Rodrigues 推导 | 指数映射把 so3 向量变成 SO3 旋转矩阵。起点是矩阵指数的泰勒级数。关键技巧是利用反对称矩阵的循环幂：K 的平方、立方、四次方会循环出现。把级数按奇偶项分类，奇数项凑成 sin θ 乘 K，偶数项凑成一减 cos θ 乘 K 平方，加上单位阵，就得到著名的罗德里格斯公式。当角度趋近于零时，用泰勒展开避免除零，得到小角度近似。 |
| 30 | Rodrigues 动画 | 动画演示罗德里格斯公式。so3 向量 w 等于 θ 乘 k，方向是转轴，长度是转角。用指数映射把它变成旋转矩阵 R，增大 θ，立方体就绕固定轴连续旋转。这也说明：任意三维旋转，都可以写成绕某一根轴转某一个角度，这就是轴角和 so3 向量的等价关系。 |
| 31 | 对数映射 | 对数映射是反过来，从旋转矩阵 R 反求旋转向量 w，相当于把姿态差变成一个可以优化的向量。三步：第一步用迹求转角，θ 等于反余弦，迹减一再除以二；第二步用 R 减 R 转置求转轴；第三步合成 w 等于 θ 乘 k。注意两个特殊情形：θ 等于零时无旋转，θ 等于派时要特别处理。指数和对数互为逆映射，把姿态和切空间向量来回搬运。 |

| 33 | se3 切空间 | se3 是 SE3 的李代数，是一个六维向量空间，前三维是平移增量 ρ，后三维是旋转增量 w。它的指数映射，旋转块还是罗德里格斯公式，平移块是一个叫左雅可比的矩阵 V 乘以 ρ。V 的作用是补偿边转边移产生的漂移，确保积分结果落在真正的 SE3 上，而不是简单地把平移直接搬过去。 |
| 34 | 四元数定义 | 四元数是 SO3 的紧凑表达。一个四元数由一个实部 w 和三个虚部 x、y、z 组成，三个虚数单位满足 i 方等于 j 方等于 k 方等于 ijk 等于负一，而且乘法不可交换。只有满足模长等于一的单位四元数才表示合法旋转。它和轴角的对应是：实部是 cos 二分之 θ，虚部是 sin 二分之 θ 乘转轴。注意是二分之 θ，这导致 q 和负 q 表示同一个旋转，叫双覆盖。 |
| 35 | 四元数运算 | 四元数有三个常用运算。第一，乘法用于姿态叠加，q1 乘 q2 表示先做 q2 再做 q1。第二，用四元数旋转向量，把向量写成纯虚四元数 p，旋转后等于 q 乘 p 乘 q 的共轭，取虚部。第三，转旋转矩阵，有一个固定的展开公式，利用模长等于一可以验证它满足 SO3 的两个约束。这样四元数和旋转矩阵就能自由互换。 |
| 36 | SLERP | SLERP 是球面线性插值。它沿球面的大圆弧，在两个姿态之间平滑过渡，夹角 Ω 由两个四元数的点积求出。它有三个好处：角速度恒定，不会忽快忽慢；路径最短；非常适合相机切换、关键帧动画和姿态目标平滑。对比右边欧拉角逐分量线性插值，会出现路径扭曲——这就是动画和姿态控制都用 SLERP 的原因。 |
| 37 | 标准链路 | 这张图总结了三者的分工，也是工程里的标准链路。姿态用四元数存储，只要四个数；要优化时，用对数映射把它变成 so3 向量，三个数、没有约束、可微可线性；在切空间里做完梯度下降，再用指数映射更新回四元数。底层的物理规则始终是 SO3，但工程师只在最外层接触它。存储用四元数、优化用李代数、推导用旋转矩阵，各司其职，缺一不可。 |

| 39 | 可微性对比 | 为什么深度学习时代必须用李代数？看这张可微性对比表。旋转矩阵九个数，带六个约束，不能直接梯度下降；四元数四个数，带模长约束，也不能；欧拉角虽然无约束，但有万向锁；只有 so3 向量，三个数、没有约束，才能直接做梯度下降。原因是：有约束的表示，做一步普通梯度更新后，就会脱离流形，不再是合法旋转。 |
| 40 | 流形梯度下降 | 所以正确做法是流形上的梯度下降。错误做法是直接对旋转矩阵减去学习率乘梯度，更新后它不再满足正交约束，仿真崩溃。正确做法分三步：网络输出一个 so3 增量 δw，三个无约束的数；当前姿态用乘法更新，R 撇等于 R 乘 δw 的指数，这样自动落在 SO3 上；最后损失对 δw 求导，反向传播。这就是 on-manifold 优化的精髓。 |
| 41 | 五大应用 | 这套数学在具身智能里有五大典型应用。SLAM 后端，用 se3 扰动加高斯牛顿优化关键帧位姿；运动规划，在 so3 上采样控制点保证轨迹光滑；全身控制，用 se3 雅可比把末端速度映射成关节速度；模型预测控制，在 se3 切空间线性化变成二次规划；视觉语言动作大模型微调，用 se3 增量做动作残差。g2o、Ceres、GTSAM 这些库，本质都在 se3 切空间上做高斯牛顿。 |

| 43 | 误区避坑 | 这一页是常见误区和避坑指南。不要对欧拉角做梯度下降，要先转 so3；不要把四元数当四维向量直接相加，要用 SLERP 或对数加指数；不要把旋转矩阵相加再投影回 SO3，直接在 so3 上加；不要忘记四元数双覆盖，比较前先对齐符号；网络不要直接输出九维旋转矩阵，输出 so3 或六维表示更稳；小角度时不要直接除以 sin θ，要用泰勒展开的数值稳定版本。 |

| 45 | 模块2·运动学（分节） | 进入模块二，机器人运动学。我们会讲三件事：正运动学，从关节角求末端位置；逆运动学，从末端位置反求关节角；以及雅可比矩阵，把关节速度和末端速度连起来。 |
| 46 | 正运动学 | 正运动学解决的问题是：已知关节角度，求末端在哪里。它是正向的、唯一的、计算简单的。本质上是一串齐次变换矩阵连乘，从基座一路乘到末端。描述连杆关系的标准方法是 DH 参数，包括连杆长度、扭转角、偏距和关节角四个量。对二自由度平面臂，末端坐标有一个简洁的闭式公式。 |
| 47 | 正运动学代码 | 这是二自由度机械臂的正运动学代码，直接套用闭式公式：x 等于第一连杆乘以 cos θ1，加上第二连杆乘以 cos θ1 加 θ2，y 同理用正弦。给定两个四十五度的关节角，就能算出末端位置。请记住：正运动学永远有唯一解，这是它比逆运动学简单的根本原因。 |
| 48 | 逆运动学 | 逆运动学正好相反：已知末端想到达的位置，反求关节角度，这要难得多。它可能有多个解，比如手肘向上或向下；可能无解，比如目标超出工作空间；还可能有无穷多解，比如冗余机械臂。动画里末端在跟随一个圆形轨迹，每一时刻都在反求对应的关节角。 |
| 49 | 逆运动学代码 | 这是用余弦定理求解的二自由度解析逆解。先算中间量 D，如果它的绝对值大于一，说明目标超出工作空间，直接判定无解；否则用反余弦求第二个关节角，再用反正切组合出第一个关节角。这里取的是手肘向上的分支。对更复杂的高自由度机械臂，通常改用数值解或优化，把逆运动学写成方程再迭代求根。 |
| 50 | 雅可比矩阵 | 雅可比矩阵把关节速度映射成末端速度，末端速度等于雅可比乘以关节角速度。对二自由度臂，它是一个二乘二矩阵。雅可比有四大用途：速度映射，关节到末端；力映射，末端力乘雅可比转置得到关节力矩；奇异性检测，行列式等于零时失去自由度；以及速度级逆运动学。特别要警惕奇异位形：行列式趋近零时，机器人在某个方向瞬间不可控，必须避开。 |

| 52 | 模块3·视觉（分节） | 进入模块三，计算机视觉数学。我们会讲图像的数学表示、卷积运算、梯度和特征提取，以及相机成像模型。这些是经典视觉和 SLAM 的数学基础。 |
| 53 | 图像表示 | 在计算机眼里，图像就是矩阵。灰度图是单通道，每个像素是零到二百五十五之间的一个数，越大越亮。彩色图是三通道，红、绿、蓝各一个矩阵。所以一张图像，本质上是一个张量。理解了这一点，图像处理就变成了矩阵运算，深度学习里就变成了张量运算——这是所有视觉算法的起点。 |
| 54 | 卷积 | 卷积是计算机视觉和深度学习的核心运算。它的本质是滑动窗口加加权求和：把卷积核放到图像的一个窗口上，对应元素相乘再求和，得到输出的一个像素，然后移动核，遍历整张图，得到特征图。动画里红框就是当前窗口。这正是卷积神经网络第一层在做的事情，不同的核能提取不同的特征。 |
| 55 | 卷积代码 | 这是手写的二维卷积，用两层循环遍历每个输出位置，取窗口和核逐元素相乘再求和。下面列了几个经典卷积核：Sobel x 提取竖直边缘，Sobel y 提取水平边缘，均值核做模糊，还有一个锐化核。同一套滑动窗口机制，换个核就能做边缘、模糊、锐化。卷积神经网络的厉害之处，就是让这些核变成可以学习的参数。 |
| 56 | 梯度与边缘 | 特征提取从梯度和边缘开始。图像梯度是 x 方向和 y 方向偏导组成的向量，通常用 Sobel 算子近似。梯度幅值等于两个偏导平方和开根号，幅值大的地方就是边缘；梯度方向指向亮度变化最快的方向。动画展示了 Sobel 边缘检测的四个阶段，从原图到 x 梯度、y 梯度，再到梯度幅值。边缘和角点，是经典视觉和 SLAM 特征点的起点。 |
| 57 | Harris 角点 | 角点是两个方向梯度都很大的点。Harris 角点检测构造一个结构张量矩阵 M，由梯度的平方和乘积累加而成。角点响应等于 M 的行列式减去 k 乘以迹的平方，响应大于阈值就判为角点。直观理解：平坦区两个特征值都小，边缘是一大一小，角点是两个都大。角点稳定、易于匹配和跟踪，是 SLAM 里最常用的特征。 |
| 58 | 相机成像 | 相机成像模型把三维世界点投影成二维像素。坐标链路是：世界系经过 SE3 外参变到相机系，再经过内参投影到图像。针孔投影方程是 u 等于焦距乘以 X 比 Z 加主点，v 同理。除以 Z 这一步，就是近大远小的数学根源。内参矩阵 K 包含焦距和主点；而相机外参，正是模块一里讲的 SE3——你看，所有模块在这里又串到了一起。 |
| 59 | 模块4·路径规划（分节） | 最后是模块四，路径规划。核心问题就一句话：从 A 点到 B 点，怎么走。我们会依次讲 BFS、Dijkstra、A 星、RRT 和 DWA 五种算法，并做对比。 |
| 60 | 路径规划概述 | 路径规划有三要素：起点到目标，约束是避障加运动学，目标是路径尽量短、平滑、安全。方法分两大类，再加一类局部规划。图搜索类，像 BFS、Dijkstra、A 星，适合栅格地图，离散且可求最优。采样类，像 RRT、PRM，适合高维空间，比如七维关节空间，是连续的、概率完备的。局部规划类，像 DWA、TEB，在速度空间搜索，用于实时避障。 |
| 61 | BFS | BFS 广度优先搜索，是所有图搜索的起点。核心思想是像水波纹一样，从起点一层层向外扩散，先到达的就是步数最短的路径。实现上用一个队列，每次取队头，把没访问过的邻居加到队尾，先进先出正好对应按距离分层。它的优点是简单、保证最少步数；缺点是把每条边权重都当成一，无法处理地形成本，而且大地图很慢。 |
| 62 | Dijkstra | Dijkstra 是 BFS 的升级版，它考虑边的权重也就是代价。核心是每次扩展当前累计代价最小的节点，用优先队列按代价排序，而不是按层数。起点代价为零，其余为无穷，不断松弛邻居，新代价更小就更新并入队。比如草地走一、沙地走三、水走五，它会自动选总代价最小的草地路径。优点是找到最短代价路径；缺点是没有方向感，向所有方向均匀扩展，比较慢。 |
| 63 | A 星 | A 星是 Dijkstra 加启发式，又快又最优。评价函数 f 等于 g 加 h，g 是已经走过的实际代价，h 是到目标的估计。按 f 排序，就会朝目标方向优先扩展，扩展的节点比 Dijkstra 少得多。看动画，左边 BFS 无差别扩散，右边 A 星直奔目标，两者都得到最优路径。启发式常用曼哈顿、欧几里得、切比雪夫距离。关键要求是可采纳，也就是估计不能高于真实代价，否则不保证最优。A 星是当今导航的标准算法。 |
| 64 | RRT | RRT 快速扩展随机树，是高维空间规划的利器。为什么需要它？因为 A 星在七维关节空间要面对十的十四次方个状态，完全爆炸，无法枚举，只能随机采样。它的做法是从起点长出一棵树，每次随机采样一个点，找到树里最近的节点，朝采样点延伸一小步，如果没撞障碍就加入树。它是概率完备的，迭代足够多次必能找到解。变体有 RRT 星、双向 RRT、Informed RRT 星。缺点是不保证最优、路径不平滑需要后处理。 |
| 65 | DWA | DWA 动态窗口法，用于实时局部避障。全局规划给出一条路径，局部规划负责实时跟踪并避开突然出现的障碍。核心是在机器人当前的速度空间里采样，每个速度组合模拟未来一小段轨迹，再打分。评分由三项组成：朝向目标的程度、离障碍的距离、以及速度大小。选评分最高的速度组合执行。DWA 是 ROS 导航默认的局部规划器之一。 |
| 66 | 算法对比 | 这张表对比五种算法。BFS 图搜索，给最少步数，适合无权小地图；Dijkstra 给最短代价，适合带权栅格；A 星加了启发式，可采纳时最优，是导航标准；RRT 和 RRT 星是采样法，概率完备或渐近最优，适合高维机械臂；DWA 是局部规划，局部最优，用于实时避障。实战里最经典的组合，就是 A 星做全局路径，加 DWA 做局部避障。 |
