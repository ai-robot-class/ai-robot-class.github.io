| 1 | 封面 | 同学们好。这一小段视频单独介绍第九周配套的参考书目。本周数学基础内容很多，课堂讲义和分节视频帮你建立框架；如果你想往下深挖，下面这几本书都值得翻一翻。其中有两本我会重点推荐。 |
| 2 | 对应关系 | 先看一张总表。《现代机器人学》和《控制之美》是两颗星的重点书，分别对应本周李群运动学和控制直觉。《概率机器人》补不确定性定位；《Corke 机器视觉与控制》偏 MATLAB 工程实现；《ROS2 机器人编程》和《Python 从入门到实践》则是后续写代码、做项目的前提。 |
| 3 | 现代机器人学 | 第一颗重点星：《现代机器人学》，机构、规划与控制。作者是林奇和朴钟宇，其中朴钟宇教授在韩国首尔大学任教——首尔大学本科生机器人课程就用这本书。这本书对机器人运动与控制背后的李群、李代数、螺旋理论讲得非常好，几何直觉清晰，不是堆公式。正运动学、逆运动学、雅可比、轨迹规划都和本周模块高度重合。如果你只想精读一本数学书来深入学习，优先选这本，官网还有免费讲义和视频可以配合。 |
| 4 | 控制之美 | 第二颗重点星：《控制之美》卷一，从传递函数到状态空间。作者王天威，就是哔哩哔哩 UP 主 DR CAN，他的控制理论视频在站内很受欢迎，书写得同样好——把经典控制理论讲得直观、好懂，传递函数、根轨迹、状态空间一条线串起来，还配有 杰纽欧克塔夫 示例和配套视频。机器人里的关节伺服、稳定性分析，和控制理论是相通的；控制基础薄弱的同学，看这本加上 UP 主的视频，再回来看雅可比和动力学会顺很多。 |
| 5 | 概率机器人 | 补充书目一：《概率机器人》，特龙等著，是定位、建图、粒子滤波、卡尔曼滤波领域的经典。它教你如何在不确定下做决策，和本周路径规划、感知模块可以互补，适合对 SLAM 感兴趣的同学选读。 |
| 6 | Corke | 补充书目二：《机器人学、机器视觉与控制》，Peter Corke 著，马特莱博算法基础。偏工程实现，运动学、视觉、控制有一体化示例，适合想把公式落到代码里的同学，和本周模块二、三配套阅读。 |
| 7 | ROS2 | 补充书目三：《ROS2 机器人编程》，韩文经典教材，作者是 Pyo 和 Lim。讲节点、话题、turtlesim 等实战入门，后续小组项目、尤其是小乌龟方向会用到 ROS2 链路，建议提前翻一翻。 |
| 8 | Python | 补充书目四：《Python 编程：从入门到实践》，图灵丛书经典，项目驱动，适合零基础。全课程的脚本和作业都默认你会 Python，没基础的同学建议先补这本。 |
| 9 | 阅读顺序 | 最后给一个阅读顺序建议：刚学完李群和李代数，就去精读《现代机器人学》相关章节；控制理论薄弱，先看《控制之美》加 DR CAN 的哔哩哔哩视频；要做项目写代码，Python 入门加 ROS2 编程；对定位和 SLAM 感兴趣，再选读《概率机器人》。这些书是帮你往下挖，不是本周必考，按兴趣选读就好。我们回到正课，继续模块学习。 |
