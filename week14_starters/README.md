# Week 14 小组项目起始代码

本目录提供第 14 周小组项目的两套起始代码：

1. `pybullet_dog/`
   - 手机网页遥控 `PyBullet` 中的四足机器人
   - 目标场景是三维迷宫

2. `turtlesim_remote/`
   - 手机网页遥控 `ROS2 turtlesim`
   - 目标场景是二维迷宫探索

两套代码都采用同一个结构：

- 一个持续运行的 Python 桥接程序
- 一个手机浏览器打开的遥控器网页
- `Tailscale` 作为手机与电脑之间的虚拟局域网

使用时的统一理解是：

- Python 程序负责监听网络、接收控制命令、控制机器人
- 手机网页只是控制输入界面
- 只要网页还在控制，桥接程序就不要关闭
